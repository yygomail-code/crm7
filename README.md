# CRM7

CRM-система для обработки заявок клиентов: складские остатки с ценами и корзиной, чат,
отчёты и администрирование.
Фронтенд — Svelte 5 + Vite + TypeScript, бэкенд — PHP 8 (REST API v2 без фреймворка) и MySQL/MariaDB.

## Возможности

- **Заявки** — создание (в т.ч. копирование прежней заявки одним действием), состав позиций,
  приоритет, срок по SLA, комментарии, вложения, смена статуса по матрице переходов,
  история изменений («Было → Стало»), передача менеджеру; стоимость позиций и итог по заявке,
  если включены цены.
- **Чат** — переписка менеджера с клиентом, привязка сообщений к заявке, вложения,
  счётчик непрочитанных, чат между сотрудниками.
- **Складские остатки** — список складов и позиций, поиск и сортировка, импорт из 1С (xls/xlsx/csv),
  экспорт (xls/xlsx/csv/txt/pdf, в т.ч. по всем складам и на e-mail), редактирование позиций.
  Настройки: **резервирование остатков** при оформлении заявки (с возвратом при удалении
  позиции и отмене заявки), **разрешение нулевых/отрицательных остатков** (позиции с минусом
  показываются с пометкой «поз заказ») и **группы позиций** (управление в админке, фильтр в
  остатках и выборе позиций).
- **Цены и корзина** — настройка «использовать цены», типы цен (розничная, оптовая, специальная…)
  и тип профиля клиента; цены задаются при редактировании позиции **для каждого склада отдельно**,
  клиент видит цену своего типа в остатках, корзине и заявке (итоговая сумма). Корзина — отдельная
  страница: количество, стоимость, итог, оформление заявки и очистка; пустая корзина показывает
  подсказку, иконка в шапке отображается при включённых продажах.
- **Клиенты** — карточка с закладками (сводная, заявки, целевой интерес к позициям, история),
  контакты, ИНН, закрепление/передача менеджера, блокировка, регистрация с подтверждением.
- **Отчёты** — по заявкам, складам, динамике, менеджерам и клиентам, сохранённые отчёты и рассылка по расписанию.
- **Уведомления, настройки системы, роли и права** — гибкая матрица прав по уровням
  (сисадмин 90, администратор 50, менеджер 10, клиент 5, гость 1), аудит действий, шаблоны писем;
  разделы админки: пользователи, роли, группы позиций, типы цен, документы, справочники, аудит.
- **Прочее** — черновики заявок, подстановки (замещения), тёмная тема, cookie-баннер, PWA-манифест.

## Стек

| Слой | Технологии |
| --- | --- |
| Фронтенд | Svelte 5 (runes), Vite 7, TypeScript, hash-роутинг |
| Бэкенд | PHP 8.2+, собственный REST API v2 (`api/`), PDO |
| БД | MySQL 8 / MariaDB 10.5+ (utf8mb4) |
| Тесты | Vitest, svelte-check, e2e на playwright-core |

## Структура

```
api/            REST API v2: controllers, services, repositories
  bin/          migrate.php, seed-dev.php, seed-demo.php, cron.php
  db/migrations нумерованные SQL-миграции
  config/       .env.example (копируется в .env)
  public/       index.php, router.php — точка входа
frontend/       Svelte 5 SPA
  src/views/    страницы (заявки, склад, клиенты, отчёты, админ…)
  src/lib/      api-клиент, компоненты, сторы
  tools/        e2e и снятие скриншотов
docs/           план, развёртывание, e2e, дизайн-ревью
```

## Требования

- PHP 8.2+ с расширениями `pdo_mysql`, `mbstring`, `openssl`, `gd` (иконки/графика)
- MySQL 8 или MariaDB 10.5+
- Node.js 20+ и npm

## Быстрый старт

### 1. API и база данных

```bash
cp api/config/.env.example api/config/.env
# укажите DB_HOST, DB_PORT, DB_NAME, DB_USER, DB_PASS и APP_KEY (64 hex-символа)

mysql -u root -e "CREATE DATABASE crm_local CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
php api/bin/migrate.php            # применить миграции
php api/bin/seed-dev.php --password=Secret123   # базовые учётные записи
php api/bin/seed-demo.php --force  # демо-данные (заявки, склад, чат) — по желанию

php -S 127.0.0.1:8080 -t api/public api/public/router.php
# API доступен по адресу http://127.0.0.1:8080/api/v2
```

### 2. Фронтенд

```bash
cd frontend
npm install
npm run dev        # http://localhost:5173
```

Адрес API по умолчанию — относительный `./api/v2`; переопределяется через
`VITE_API_V2_BASE` при сборке или `window.CRM_CONFIG` в `config.js` (см. `docs/deploy.md`).

### 3. Планировщик

```bash
php api/bin/cron.php   # рассылки отчётов, SLA-уведомления, передачи клиентов — раз в минуту
```

## Тесты

```bash
cd frontend
npm run check      # svelte-check (типы и разметка)
npm run test       # Vitest
npm run build      # production-сборка
npm run e2e        # e2e-сценарии (нужен запущенный фронтенд и API)
```
