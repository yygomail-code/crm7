# Импорт реальных данных клиента в K

Цель: загрузить реальную базу клиента **только в окружение K**, не затронув и
не «залив» её в test/demo, и не утечь в git/образы/интернет.

## Правила
1. Дамп живёт **вне репозитория**: `/srv/shared/imports/` (права `0600`).
   В git он не попадёт (`.gitignore`: `imports/`, `*.sql.gz`, `*.dump`, `*.dump.gz`).
2. Импорт адресный — только K (`crm7-k-db`, база `crm7_k`). Скрипт жёстко
   нацелен на K и **отказывается** работать с другими целями.
3. Перед импортом — **бэкап текущей K** (скрипт делает автоматически в
   `/srv/shared/backups/`).
4. После импорта — **удалить дамп**.
5. Сиды на K не запускаются. `seed-demo.php` теперь отказывается работать вне
   demo-режима без явного `--allow-non-demo` (защита от случайной очистки K).

## Как импортировать
1. Принять дамп по защищённому каналу (SFTP/SCP) и положить в `/srv/shared/imports/`.
2. Запустить (для дампа в формате CRM7 / `mysqldump` одной базы):
   ```bash
   /srv/import_k.sh /srv/shared/imports/<file>.sql        # спросит подтверждение
   /srv/import_k.sh /srv/shared/imports/<file>.sql.gz --yes
   ```
   Скрипт: проверяет цель → делает бэкап K → импортирует → накатывает миграции
   (`migrate.php`) до текущей версии кода.
3. Проверить K (`k.crm7.local` / `k.crm7.ru`): вход, список, данные.
4. Удалить дамп: `rm -f /srv/shared/imports/<file>.sql*`.

## Если база клиента НЕ в формате CRM7
Прямой restore не подойдёт — нужен **ETL**: скрипт, который читает исходную
базу, преобразует и заливает в таблицы CRM7. Порядок тот же: исходник вне
репозитория, заливка только в K, после — удалить исходник. ETL-скрипт хранится
в отдельном приватном месте (не в этом репозитории, если содержит реальные данные).

## Защита от попадания в test/demo
- Импорт-скрипт знает только K; для test/demo его запустить нельзя.
- `seed-demo.php` вне demo-режима требует `--allow-non-demo`.
- Полный сброс demo — только `/srv/projects/crm7-demo/reset-demo.sh`.
- Порты БД наружу не публикуются (см. `docs/images.md`).

## Замечание
Базы окружений однозначны: **`crm7_test`**, **`crm7_demo`**, **`crm7_k`** — перепутать
сложно. Реальный импорт возможен только в `crm7_k` (скрипт `/srv/import_k.sh`).
