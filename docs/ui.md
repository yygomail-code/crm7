# UI: дизайн-система (Ant Design)

Интерфейс приводится к рекомендациям Ant Design. Общие токены — в
`frontend/src/app.css` (`:root`); компоненты — в `frontend/src/lib/components/ui/`.

## Токены

Цвета:
- Основной: `--primary #1677ff`, `--primary-hover #4096ff`, `--primary-active #0958d9`, `--primary-bg #e6f4ff`, `--primary-border #91caff`.
- Текст: `--text rgba(0,0,0,.88)`, `--muted rgba(0,0,0,.65)`, `--text-description rgba(0,0,0,.45)`.
- Границы/заливки: `--border #d9d9d9`, `--border-secondary #f0f0f0`, `--fill-tertiary rgba(0,0,0,.02)`, `--fill-hover rgba(0,0,0,.06)`, `--focus-ring rgba(5,145,255,.1)`.
- Статусы: `--danger`, `--danger-bg`, `--error-border`, `--error-text #cf1322`; `--success`, `--success-bg`, `--success-border`, `--success-text #389e0d`; `--warning`, `--warning-bg`, `--warning-text #d48806`.

Прочее:
- Радиусы: `--radius-sm 6px`, `--radius-md 8px`. Тени: `--shadow-sm`, `--shadow-md`.
- Отступы: `--space-1..6` = 4/8/12/16/24/32. Контролы: `--control-height 32px`.
- Шрифт: `--font` (системный), база 14px / line-height 1.5714.

**Правило:** не хардкодить цвета вне токенов Ant — использовать переменные.

## Размеры

- Контролы (инпуты, селекты, кнопки, иконочные кнопки, пагинация) — **32px** (Ant default).
- Иконки внутри кнопок — **16px**.
- Радиус контролов — 6px; карточек, модалок и панелей — 8px.
- Фокус полей — `border-color: var(--primary)` + `box-shadow: 0 0 0 2px var(--focus-ring)` (Ant controlOutline).

## Иконки

- `frontend/src/lib/components/ui/Icon.svelte` — карта имён → иконки из `@ant-design/icons-svg`.
- Использование: `<Icon name="edit" size={16} />`.
- Иконка рендерится как `<svg fill="currentColor">` — цвет задаётся через `color` родителя.
- **Добавить иконку:** импортировать `XxxOutlined`/`XxxFilled` из `@ant-design/icons-svg/es/asn/...`
  и добавить запись в объект `icons` (ключ — короткое имя).
- Текущие имена: `admin`, `arrow-*`, `bell`, `camera`, `cart`, `chat`, `check-circle`, `clients`,
  `close`, `close-circle`, `edit`, `export`, `group`, `help`, `import`, `info`, `my-reports`,
  `picture`, `plus`, `reports`, `requests`, `settings`, `sort`, `stocks`, `substitutions`, `view`.

## Компоненты (`frontend/src/lib/components/ui/`)

- **`Button.svelte`** — `variant: 'primary' | 'ghost' | 'text' | 'danger'` (по умолч. `primary`),
  `size: 'md' | 'sm'` (32px), `loading`, `disabled`, `title`, `ariaLabel`, `onclick`.
- **`Modal.svelte`** — общий шелл: `open`, `title`, `label`, `wide`, `closeButton`, `bodyMinHeight`, `onclose`.
  Рендерится только при `open`; Escape и клик по маске закрывают.
- **`Input.svelte`** — `label`, `type`, `value` (bindable), `placeholder`, `error`, `name`. Высота 32.
- **`SearchInput.svelte`** — поиск с историей (`historyKey`), `onclear`, `onpick`.
- **`Spinner.svelte`** — `size` (по умолч. 18).
- **`Pagination.svelte`** — `page`, `perPage`, `total`, `onchange`, `onperpage`, `perPageOptions`, `always`, `loading`.
- **`FiltersModal.svelte`** — кнопка «Фильтры» + модалка (`onapply`, `onreset`, `onopen`, `count`).
- **`ExportModal.svelte`** — выбор формата (XLSX/XLS/CSV/TXT/PDF) и способа (скачать/почта), `onpick(format, byEmail)`.
- **`Logo.svelte`**, **`BarChart.svelte`** — логотип и гистограмма.
- **`stocks/PhotoGallery.svelte`** — галерея фото: `photos`, `variant: 'list' | 'tile'` (tile — свайп/стрелки), `onopen`, `flush`. Пропорции/вписывание и размер запрашиваемого варианта берутся из настроек (список → `preview`, tile → `card`).

## Склады

Страница «Склады» (пункт навигации, если включён `module.warehouses` и есть `stocks.import`/`stocks.edit`)
оформлена как «Номенклатура»: тулбар `[Сортировка][Отображение] │ [Добавить][Экспорт] │ [Хелп]`, два вида
(таблица с шапкой и сортировкой по клику + плитки), блок перелистывания внизу, фоновое автообновление
(`config.listPollMs`, 30 с). Счётчика складов нет; фото у складов нет, поэтому опций «с фото» нет. Под
названием — тип (если не «основной»), адрес и ответственный; у «основного» склада — тег «основной».

Карточка склада — три вкладки:

- **Основное** — реквизиты (`Название`, `Название в 1С`, `Номер`, `Порядок`), тип (селект) и ответственный
  (кнопка-контрол → модалка-пикер: поиск + список, выбор только среди менеджеров и администраторов),
  флаги: «Основной склад», «Доступен для заявок и самовывоза» (если включён модуль «Заявки»),
  «Учитывать в отчётах» (если включён модуль «Отчёты»), «Активен (показывать позиции на этом складе)»;
- **Контакты** — адрес, контактное лицо, телефон, e-mail, комментарий;
- **Доступ** — роли склада (`stocks.LEVEL`, чекбоксы Сисадмин/Администратор/Менеджер/Клиент) и персональный
  список пользователей (убрать с подтверждением).

Скрытый склад не виден пользователям, но импорт на него идёт. Добавление доступа — модалка-пикер: таблица
пользователей (ФИО / логин / роль / доступ) с поиском, фильтром по ролям (Сисадмин/Администратор/Менеджер)
и сортировкой по клику; показываются активные пользователи выбранных ролей, а те, у кого доступ уже есть,
помечены тегом «есть доступ» (`GET /stocks/warehouses/{id}/candidates`). Кнопка «Добавить» и тег «есть
доступ» — одного размера (Ant small, 24px). Добавление склада — отдельная страница `#/warehouses/new`
(та же карточка в режиме создания: вкладки «Основное»/«Контакты», без «Доступа»; «Создать» →
`POST /stocks/warehouses` → переход в карточку). Экспорт списка — `ExportModal` →
`GET /stocks/warehouses?export=<format>`. При отключённом модуле склады не отображаются (один
«виртуальный» склад).

## Фото номенклатуры

Формат отображения — системная настройка (`#/settings` → «Система»); применяется к плиткам, строкам, карточке позиции и ItemEdit:

- **формат** (`stocks.photo_ratio`): динамический (по фото) / квадрат 1:1 / горизонтальный 4:3 / вертикальный 3:4;
- **несовпадение пропорций** (`stocks.photo_fit`): вписывать (без обрезки, по умолчанию) / заполнять (с обрезкой);
- **размеры вариантов** по длинной стороне, px (`stocks.photo_size_preview/card/max`, дефолт 160/600/1600).

Список запрашивает `preview`, плитки/карточка/просмотр — `card`, полный размер — `max`. При загрузке фото уменьшается до `max` и генерируются варианты `card`/`preview` (см. [`architecture.md`](architecture.md)).

## Карточка позиции

`#/stocks/items/:id/edit`; создание — `#/stocks/items/new` (без выбора склада: позиция общая, остатки
задаются после создания). Позиция единая для всех складов: вкладка «Основное» — тип позиции (только
разрешённые типы), общие поля (название, артикул, единица измерения — селект из основных единиц, группа,
описание) и цены текущего склада; вкладка «Количество» — общий остаток и список **всех доступных складов**
(остаток можно задать на любом — уровень создаётся при сохранении, текущий отмечен тегом); вкладка
«Состав» (у набора) — список компонентов с количеством, добавление через пикер поиска по
названию/артикулу. Переименование меняет позицию на всех складах. В шапке — статус «деактивирована» и
кнопки «Деактивировать/Активировать» (право `stocks.deactivate`) и «Удалить» (право `stocks.manage`;
причина запрета — в подсказке кнопки). Табы — подчёркиванием (как в карточке склада).

Деактивированные позиции в списке номенклатуры подсвечены фоном и тегом «деактивирована»; в модалке
«Сортировка» роли с правом доступен блок «Показывать: Все/Активные/Неактивные» (у остальных — только
активные). У деактивированной позиции скрыты кнопки корзины.

## Администрирование

`#/admin` — вкладки: **Модули · Типы позиций · Пользователи · Журнал аудита · Поиски позиций · Роли · Справочники ·
Группы позиций · Документы**. Вкладка «Модули» (нужно `settings.manage`): карточки модулей — тумблер
вкл/выкл, код и описание, чекбоксы «Доступно ролям» (Сисадмин/Администратор/Менеджер/Клиент/Гость).
Доступ ролей выдаётся правами (пишется в `level_capabilities`); матрицу ролей может менять только
сисадмин (`roles.manage`), остальным она показана отключённой. «Сохранить» — `POST /admin/modules`.

## Паттерны страниц

- **Клик по строке/плитке:** «Склады» — вся строка/плитка открывает карточку склада (название остаётся
  ссылкой для клавиатуры/новой вкладки, клик по ней не дублируется). «Номенклатура» — вся строка открывает
  карточку позиции, но корзина («Добавить», «−/+») перехватывает клик (`stopPropagation`) и карточку не
  открывает. Интерактивно только название (единственный доступный элемент) — остальные тексты (мета, статы)
  обычные; при ховере строки название подсвечивается `--primary`.
- **Поиск и возврат из карточки:** поисковый запрос и номер страницы входят в сохранённые фильтры списка
  (`stocks`/`warehouses`), поэтому при возврате из карточки список открывается на том же поиске, странице и
  фильтрах. `SearchInput` помнит последние поиски (localStorage `crm.search.<key>`) и показывает их по
  фокусу при пустом поле — на «Номенклатуре» и «Складах».
- **Отступы (канон, Ant; едино на «Номенклатуре» и «Складах»):** страница — `gap` 16 (`--space-4`);  шапка (`h1` + подзаголовок) — колонка, `gap` 4 (`--space-1`), подзаголовок без внешнего margin;
  тулбар — `gap` 16; строка списка — `padding: 12px 16px`, `gap` 12; сетка плиток — `gap` 16;
  плитка — контентный отступ 12 (`--space-3`) (у плитки с фото фото во всю ширину, внутренние отступы 12);
  блок перелистывания — `gap` 12, контролы 32px.

- **Заголовок:** `h1` 20px / 600 / `--text`; подзаголовок 14px `--text-description`.
- **Тулбар:** фильтры слева, действия справа; разделители — 1px × 24, `--border-secondary`.
- **Таблица:** шапка `--fill-tertiary`, текст 600 / `--text`, разделители `--border-secondary`,
  числа по правому краю, пагинация 32px.
- **Модалки:** заголовок 16/600, футер `[Отмена] [Действие]` справа.
- **Alert/notice:** иконка + рамка + тёмный текст на цветном фоне (`--danger-bg`/`--success-bg`).
