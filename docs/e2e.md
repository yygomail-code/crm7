# E2E-проверки CRM7

Лёгкий набор e2e-сценариев на `playwright-core` + системный браузер (без скачивания
браузеров). Проверяет критичные пользовательские пути поверх запущенного стенда.

## Запуск

```powershell
# стенд: API (php -S) + фронтенд (vite) + БД с демо-данными
$env:CRM_BASE_URL = 'http://localhost:5174'
$env:CRM_API_URL = 'http://127.0.0.1:8080/api/v2'
$env:CRM_PASSWORD_FILE = "$env:TEMP\opencode\seed_passwords.json"
npm run e2e
```

Переменные окружения:

| Переменная | Назначение | По умолчанию |
| --- | --- | --- |
| `CRM_BASE_URL` | адрес фронтенда | `http://localhost:5174` |
| `CRM_API_URL` | адрес API v2 | `http://127.0.0.1:8080/api/v2` |
| `CRM_PASSWORD_FILE` | JSON `{"login": "password"}` | — |
| `CRM_PASSWORD` | общий пароль для всех ролей | — |
| `CRM_BROWSER_CHANNEL` | канал Playwright (`msedge`, `chrome`); `bundled` — встроенный chromium | `msedge` |
| `CRM_HEADED=1` | показать окно браузера | headless |
| `CRM_E2E_ONLY` | фильтр сценариев по подстроке имени (через запятую) | все |

Примеры:

```powershell
# только сценарии чата и склада
$env:CRM_E2E_ONLY = 'чат,склад'; npm run e2e

# отладка с окном
$env:CRM_HEADED = '1'; npm run e2e
```

## Сценарии (`frontend/tools/e2e/run.mjs`)

1. Вход через форму и выход (роль `manager`) — форма входа, навигация, вкладка «Сессии»,
   выход из текущей сессии, возврат на экран входа.
2. Заявки: карточка и вкладки — список, карточка заявки с позициями, вкладки
   «Состав»/«Комментарии»/«История».
3. Чат: отправка сообщения — открытие треда, ввод и отправка, появление сообщения.
4. Склад: поиск и сортировка — поиск «iPhone», отсутствие кнопки фильтров, сортировка
   «Количество: по убыванию».
5. Отчёты: переключение вкладок — плитки, «По складам», «Динамика», «По статусам» (столбец «Доля»).
6. Админ: роли — группы прав — свёрнутые группы, раскрытие «Заявки», наличие чекбоксов.
7. Админ: аудит — русские подписи — подпись действия и технический код.
8. Заявки: пустое состояние при фильтрах — список, фильтр по периоду, «Заявки не найдены»,
   «Сбросить фильтры».
9. Новая заявка: выбор клиента из поиска — поиск, выбор клиента, создание заявки.

Сценарий 3 добавляет сообщение в чат (аддитивно), сценарий 1 завершает только свою сессию —
остальные данные не меняются.

## Результат

- Успех: `Итог: N/N сценариев пройдено`, код выхода `0`.
- Ошибка: код выхода `1`, скриншот упавшего экрана в `frontend/artifacts/e2e/` (каталог в `.gitignore`).

## CI

Job `frontend:e2e` в `.gitlab-ci.yml` — **manual**: требует запущенного стенда и доступных
переменных `CRM_BASE_URL`/`CRM_API_URL`/`CRM_PASSWORD`; использует образ
`mcr.microsoft.com/playwright` со встроенным chromium (`CRM_BROWSER_CHANNEL=bundled`).
